# NODUS: Unified Academic Knowledge Network

NODUS is a 4-year interconnected college learning platform featuring an Obsidian-style Knowledge Graph, Semester Locking mechanisms, section-wise Faculty Assignment uploads, automated countdown timer alerts, and a syllabus-grounded AI Tutor.

## Tech Stack
- **Frontend**: Next.js, React, Tailwind CSS, React Flow
- **Backend**: Python FastAPI, SQLAlchemy, PyODBC
- **Database**: Microsoft SQL Server
- **AI/RAG**: LangChain, Pinecone, Vector Database

## Quick Start
```bash
docker-compose up --build
```
